## ✨ المميزات الرئيسية

* 🎵 **تشغيل مستمر 24/7:** البوت لا يتوقف، يبحث تلقائياً عن الفيديوهات، ويستأنف التشغيل حتى بعد إعادة تشغيل السيرفر أو انقطاع الشبكة.
* 🪙 **نظام اقتصاد ومجتمع:** 
  * يحصل المستمعون على **نقطة واحدة** لكل 15 دقيقة استماع.
  * نظام **مستويات** (مبتدئ 🥉، مستمع 🥈، مخلص 🥇، أسطورة 💎).
  * **9 أوسمة (Badges)** تفاعلية (سهران، وفي، مدمن، إلخ).
* 🕹️ **تحكم تفاعلي بالنقاط:**
  * أمر `/تخطي` لتخطي المقاطع مقابل نقاط.
  * أمر `/افضل_مقطع` لفرض مقطع كأولوية في الطابور.
* 📡 **دعم البثوث المباشرة:** أمر `/بث` لتشغيل بثوث يوتيوب المباشرة (Live Streams) بسلاسة.
* 🛠️ **محرك صوتي متطور (Modular):** 
  * تبديل ديناميكي وتلقائي بين مزودات `PoT (Proof of Token)` لتخطي حظر يوتيوب.
  * نظام "Preload" لتحميل المقطع التالي قبل انتهاء الحالي لانتقال بدون تقطيع.
  * تحديث ذكي لواجهة ديسكورد (Now Playing) لتخفيف استهلاك الـ API.
* 📊 **لوحة تحكم (Web Dashboard):** واجهة API ونقطة فحص صحة (`/api/health`) لمراقبة أداء البوت والمزودات النشطة.

## 💻 أوامر البوت (Slash Commands)

| الأمر | الوظيفة | التكلفة / الصلاحية |
|---|---|---|
| `/نقاطي` | يعرض رصيد نقاطك، مستواك، والأوسمة التي حصلت عليها. | مجاني |
| `/تخطي` | يتخطى المقطع الحالي لتشغيل المقطع التالي. | 10 نقاط |
| `/افضل_مقطع` | يضع المقطع المطلوب كأول مقطع سيعمل بعد الحالي مباشرة. | 20 نقطة |
| `/بث` | يبدأ بث مباشر من رابط يوتيوب في الروم الصوتي. | مجاني |
| `/اظهار_احصائياتي`| اختيار السماح أو منع ظهورك في قائمة المتصدرين. | مجاني |

## ⚙️ متطلبات التشغيل

تأكد من توفر البرامج التالية على السيرفر قبل البدء:
1. [Node.js](https://nodejs.org/) (إصدار 18 أو أحدث)
2. [FFmpeg](https://ffmpeg.org/) (يجب أن يكون مُضافاً إلى `PATH` في النظام)
3. [Python 3](https://www.python.org/) (مطلوب لعمليات yt-dlp)

## 🚀 التثبيت والتشغيل

1. **استنساخ المشروع وتثبيت الحزم:**
```bash
git clone https://github.com/m7kor/L6mh.git
cd L6mh
npm install
```

2. **إعداد المتغيرات البيئية:**
قم بنسخ ملف `.env.example` إلى `.env` وقم بتعبئة البيانات:
```bash
cp .env.example .env
```
*أهم المتغيرات المطلوبة:* `DISCORD_TOKEN`, `CLIENT_ID`, `YOUTUBE_API_KEY`, `CHANNEL_ID`.

3. **تسجيل الأوامر في ديسكورد (مرة واحدة فقط):**
```bash
npm run deploy
```

4. **تشغيل البوت:**
```bash
npm start
# أو في بيئة التطوير
npm run dev
```

## 📁 هيكلية المشروع (Architecture)

تمت هندسة البوت حديثاً ليصبح مرناً وقابلاً للتوسع بشكل كبير:

```text
src/
├── commands/         # أوامر ديسكورد (skip, points, priority, live)
├── services/
│   ├── player/       # محرك الصوت المجزأ (القلب النابض للبوت)
│   │   ├── engine.js     # الاتصال الصوتي والتشغيل والـ Preload
│   │   ├── controls.js   # أوامر التحكم (إيقاف، استكمال، الخ)
│   │   ├── jingles.js    # المؤثرات الصوتية والفواصل
│   │   └── ui-updater.js # تحديث رسالة "الآن يعمل" في ديسكورد
│   ├── community.js  # نظام النقاط والمستويات وإدارة الجلسات
│   ├── streaming.js  # اتصال yt-dlp وتبديل PoT Providers
│   ├── youtube.js    # التعامل مع YouTube API والتخزين المؤقت
│   └── session.js    # حفظ وإدارة حالة التشغيل في قاعدة البيانات
├── utils/            # أدوات مساعدة (Database, Logger, Embeds, Status API)
├── lang.js           # المركز الموحد لجميع النصوص والمسميات العربية
└── index.js          # نقطة الدخول الرئيسية
```

* ملف قاعدة البيانات: `data/bot.db`
* لحفظ نسخة احتياطية، يكفي نسخ مجلد `data/`.
