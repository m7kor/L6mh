## ✨ الميزات

### 📻 راديو مستمر
- **بث 24/7** من فيديوهات قناة وحيد عمر
- **خوارزمية shuffle-bag** — تخطي بدون تكرار حتى انتهاء الدورة
- **انتقال متقاطع (Crossfade)** بمزج equal-power — لا انقطاع ولا صمت بين المقاطع
- **تحميل مسبق (Preload)** — المقطع التالي يُفكّ قبله ويبدأ فوراً
- **تنقل ذكي** بين القنوات الصوتية حسب عدد المستمعين
- **مؤثرات صوتية** ترحيبية عند الدخول (اختياري)

### 🔧 كفاءة التشغيل
- **عملية yt-dlp واحدة لكل مقطع** (كانت 3: تحقّق + فحص بث + بث)
- **مراقبةازمة التوقف** عبر عدّ البايتات المنتَجة فعلياً — بلا فقدان صوت
- **مسار صوتي حي (live handle)**: يمكن اعتماد بث مُحمَّل مسبقاً بدل إعادة التشغيل

### 🌐 لوحة تحكم ويب (`/`)
- **تصميم عصري** بالdark mode
- **Now Playing** مع شريط تقدم مباشر + أزرار تحكم
- **إحصائيات حية**: مدة التشغيل، عدد المقاطع
- **قائمة مقاطع** مع بحث/فلترة/تشغيل + فلتر "لم تُشغَّل بعد"
- **سجل أخطاء** + **حالة النظام** (yt-dlp، PoT Provider، الكوكيز، قاعدة البيانات)
- **دخول دائم** — التوكن ينحفظ تلقائياً
- **Kiosk Mode** (`/admin/kiosk`) — نسخة مبسّطة للعرض على شاشة

### 📺 صفحة عامة (`/live`)
- **بدون تسجيل دخول** — متاحة للجميع
- Now Playing + إحصائيات + آخر ما شُغّل
- **لوحة الشرف** — Top 100 أكثر الأعضاء استماعاً

### 🛡️ استقرار
- **Race condition free** — SQLite بدل JSON
- **Stall Detection** — يكتشف التوقف ويتخطاه تلقائياً
- **Graceful Shutdown** — حفظ الحالة عند الإيقاف، حتى عند انهيار غير متوقع
- **حدود معدّل** على نقاط التحكم: 30 طلب/دقيقة لكل IP، مع cooldown على الأوامر
- **مهلة مشاهدة (watchdog)** لكل انتقال متقاطع — يعود للتبديل المباشر إن لم يُنتج صوتاً

### 🧭 تعافٍ حقيقي (يعمل 24/7)
كل هذه مسارات فشل كانت تُنتج **صمتاً أبدياً** أو **تسريباً تراكمياً** — لا انهياراً ظاهراً:

| الحالة | ما كان يحدث | الآن |
|--------|--------------|------|
| انقطاع الشبكة (UDP) | لا يوجد معالج لـ `Destroyed` → لا حدث تعافٍ إطلاقاً، والبوت يبقى «متصلاً» صامتاً | معالج لكل الحالات الطرفية، مع استرجاع مضمون مرة واحدة |
| البوت مُزال من السيرفر | سلّم إعادة اتصال لا ينتهي (مهلة 60s كل دورة) للأبد | `GuildDelete` يحرّر الجلسة، وسقف للمحاولات |
| فشل الجينغل | وعد لا يُحسم أبداً → `connectAndPlay` يعلّق، ويبقى المشغّل الرئيسي غير مشترك | مهلة قصوى + إعادة اشتراك مضمونة |
| تداخل طلبات التشغيل | لاعبان + عمليتان على مقعد صوتي واحد | تذكرة تصاعدية: الطلب الأحدث فقط هو من يلتزم |
| موت yt-dlp + ffmpeg | يتسرّب في كل انتقال | كل مقود له مالك صريح، وقُطّاع يتخلّص من الأيتام |
| انقطاع طويل | نقطة الاستئناف تتجاوز نهاية المقطع ← يُحذف الفيديو السليم بعد 3 محاولات | التقدّم مقصوص عند المدة الحقيقية |
| فشل بدء التشغيل | استثناء واحد يُعطّل كل الأنظمة بصمت | كل نظام يبدأ مستقلاً، وكل فشل يُسجَّل |
| قياس صحة البوت | `alive: true` دائماً — لا يكشف صمت البوت | إشارة gateway + عدّ العمليات الأيتام |

## ⚙️ التثبيت والتشغيل

### المتطلبات
- Node.js 18+
- yt-dlp
- FFmpeg

### 1. التثبيت
```bash
git clone https://github.com/m7kor/L6mh.git
cd L6mh
npm install
```

### 2. إعداد المتغيرات
أنشئ ملف `.env` من `.env.example`:
```bash
cp .env.example .env
```

ثم عدّل القيم المطلوبة:
```env
DISCORD_TOKEN=توكن البوت
CLIENT_ID=معرّف التطبيق (Application ID)
YOUTUBE_API_KEY=مفتاح YouTube API
CHANNEL_ID=معرّف القناة
DASHBOARD_TOKEN=كلمة سر الداشبورد
STATUS_PORT=3333
# دعوة ديسكورد صالحة — تظهر كزر «استمع عبر ديسكورد» في الصفحة العامة.
# بلا قيمة: الصفحة تعرض ملاحظة فقط بلا زر (مقصود — لا أزرار مزيّفة).
DISCORD_INVITE_URL=
```

#### متغيّرات يُنصح ضبطها في الإنتاج

| المتغيّر | لماذا |
|---------|--------|
| `CORS_ORIGINS` | نطاق اللوحة علناً. **بلا قيمة تُرفض الطلبات الخارجية** — لا `*` |
| `TRUST_PROXY` | عدد طبقات الوكيل. بدونه ينهار حدّ المعدّل إلى «-global» لكل الزوار |
| `STATUS_HOST` | `127.0.0.1` افتراضياً. لـ Docker يجب أن يكون `0.0.0.0` وإلا لن يستقبل المنفذ المنشور شيئاً |
| `CROSSFADE_SECONDS` | طول المزج. `0` = تبديل مباشر |
| `SOUND_EFFECTS_ENABLED` | المؤثرات الصوتية بين المقاطع |
| `HEALTH_WEBHOOK_URL` | إشعارات الأخطاء والتعذّرات مباشرةً في ديسكورد |

### 3. التشغيل
```bash
# تطوير
npm run dev

# إنتاج (PM2)
pm2 start ecosystem.config.cjs
pm2 save

# الاختبارات
npm test
```

### 4. أوامر مفيدة
```bash
pm2 restart yt-audio-bot    # إعادة تشغيل
pm2 logs yt-audio-bot       # متابعة السجلات
pm2 status                  # حالة البوت
```

### ملكية الموارد — القاعدة الحاكمة

كل عملية خارجية ومورد لها **مالك واحد معروف**، وكل مسار يستبدل مورداً **يجب** أن يحرّر القديم:

| المورد | المالك | يُحرَّر عند |
|--------|--------|------------|
| `yt-dlp` + `ffmpeg` | `AudioStreamHandle` | انتهاء المقطع، أو `kill()` |
| المقطع المحمَّل مسبقاً | `session.preloaded` | التبنّي، أو الاستبدال، أو الإيقاف |
| المقطع المُختار ولم يُشغَّل بعد | `session.pendingHandle` | التبنّي، أو الإلغاء، أو أي انتقال آخر |
| شريط المزج | `session.outgoingTape` | اكتمال المزج، أو بداية مسار جديد |
| مؤقّتات الانتقال | `crossfadeTimer` / `tapeTimer` / `preloadTimer` / `rejoinTimer` | الإيقاف، أو المقطع الجديد |

> `preloadTimer` و `pendingHandle` تحديداً كانا **غير قابلين للتحرير**: مؤقّت ملقًى بلا مرجع، ومُلكية ضائعة. هذان كانا مصدر أكبر تسريب في المشروع (عمليتا yt-dlp + ffmpeg تتسرّبان في كل انتقال).

## 🧪 الاختبارات

**207 اختباراً** — `npm run verify` = typecheck + lint + الاختبارات + build.

```bash
npm run verify   # كل شيء
npm test         # كل الأجنحة
npm run typecheck
npm run lint
```

| الأجنحة | التغطية |
|---------|---------|
| `crossfade.test.ts` | نافذة equal-power، عدم فقدان أي إطار، محاذاة الإطارات، تدهور رشيق عند نقص الصوت |
| `crossfade.integration.test.ts` | قيدان حقيقيان: تبديل الاشتراك، وشريط مُسجَّل مسبقاً |
| `engine.crossfade.test.ts` | تسليح المؤقّتات، الإفراج عن السلسلة الخارجة، التراجع عند غياب شريط |
| `engine.test.ts` | سلسلة فلتر ffmpeg، تصنيف أخطاء PoT، دورة حياة الـ preload، عدّاد البايتات |
| `ownership.test.ts` | **ملكية الموارد** — تبنّي/إفلات كل مقود، تحرّر المؤقّتات، قصّ التقدّم، كاش بحدّ أعلى، سياسة قُطّاع الأيتام، شكل الجلسة |
| `jingles.test.ts` | **كل وعد يُحسم** — جينغل يتعثّر، ملف تالف، مهلة قصوى |
| `tests.test.ts` | formatTime, cookies, videoId, cooldown, queue, database, stats, session, embeds, lang, killProcesses |
| `unit-modules.test.js` | استدلال حالة التشغيل، التحقق من الدعوات، تعقيم المدخلات، عارض الحالة |
| `tests/*.test.js` | سلوك الصفحات الحقيقية عبر jsdom — تعافي الاتصال، مصباح «على الهواء» الصادق، CTA ديسكورد، زر الإيقاف، توست الفواصل |
| `live-updates.test.js` | حلقة التحديث: لا تداخل، لا مضاعفة، تعافٍ صادق |

- يستخدم **in-memory SQLite** — لا يلمس قاعدة الإنتاج
- `tests.test.ts` كان يغطي فرعَي `ffmpegProcess` و `resolveProcess` في `killProcesses` — فرعان **لا يمكن أن يُنفَّذا** لأن الحقلين لم يُسنَدَا قط. حُذفت الاختبارات مع الحقول: التغطية على مسار ميّت ليست تغطية.

> الصوت الفعلي (الجودة، الانتقال المتقاطع) يحتاج اختباراً يدوياً في قناة صوتية؛
> الاختبارات أعلاه تثبت منطق المزج ومعالجة التيارات، لا تجربة الصوت نفسها.

### أين كانت الأخطاء مختبَأً

الأخطاء الثمانية الكبرى عاشت كلها في **نقاط الوصل بين الوحدات** — لا داخل أي وحدة. الاختبارات كانت كثيفة على الكتل النقيّة (20 حالة لمزج الانتقال) وصفراً على ما يليه: تسلّم الـ preload، تداخل الطلبات، تحرير ما يُستبدل، تعافّي الاتصال.

> **قاعدة تعلّمية:** الاختبارات الكثيفة على وحدٍ نقيّ تمنح ثقة زائفة. ما لم يُختبر هو بالضبط ما ينكسر.
